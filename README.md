# Nova Raphaella — entrada de notas

Página do sistema de entrada de notas da Nova Raphaella (https://notas.novaraphaella.com.br).

- `index.html` é a página publicada. Cada versão nova é enviada para cá e, em seguida, copiada para a nuvem (Supabase), de onde o site a serve.
- Não há senhas nem dados de clientes neste repositório. O acesso aos dados exige login com e-mail autorizado.
